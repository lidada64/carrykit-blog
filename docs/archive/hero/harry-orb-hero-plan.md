# 哈利与灯球 Hero 滚动路线

更新：2026-10-20。首页已采用 CampfireHero；旧 HomeHero 已归档至 `/lab/hero-archive`。本文件仅规划下一阶段，尚未实现下滑演出。此版覆盖旧计划的连续滚动绑定与「不使用Observer」约束，采用用户指定的短暂页面接管。主题、字体与人物姿态保持。

## 当前起点

- 默认滑块Orbit −34°、Elevation 12°，1-bit模式；保留手动相机和模式切换。
- 当前哑光格纹球体在火光下保持柔和受光，暗格缝可见；球极轴与世界Z一致，倾角0。镜片本身的局部倾斜用于反射，和球轴倾斜不同。
- 大标题在场景后方，当前位置不变。归档页仅作灯球点亮、吊线和停靠形态参考，不复用其点击坠落逻辑。

## 分镜与节奏

首次有效下滑触发完整时间线；进度代表演出时间，不是滚动距离。总时长先用既有slow动效token的3倍作为试作，再按观感微调。

| 进度 | 画面 | 约束 |
| --- | --- | --- |
| 0–15% | 当前近景短暂保持，标题与调节面板淡出 | 接管期间停止镜头调节，保存触发时视角，不突跳回默认 |
| 10–55% | 整组缩小，巨大球面逐渐露出完整轮廓 | 哈利、火堆、烟雾、烤棍随球同比缩小，无独立滑移；Canvas仍占满视口 |
| 35–70% | 球体从暗镜面渐亮，先见反射，再亮起填缝与微弱光晕 | 延后到球形可读时再点灯；1-bit沿用主题两色，不把球冲成白圆 |
| 55–90% | 吊线显露，亮灯球沿竖直方向被提至画面上部 | 挂点避开哈利/火焰；球不自动旋转，不新增摆动 |
| 90–100% | 减速停稳，保留顶部悬挂灯球 | 终态下一次下滑释放到正文；不新增全站悬浮挂件 |

桌面终态先对齐归档页球径与导航安全区，建议144–240px、球心在视口25–30%高度；窄屏按主体可辨认及导航间距调整。尺寸在Lab验收后固化为token。

## 分三步实施

### 1. Lab先验证整球与亮灯

在现有Lab增加开发用0–1进度控制，先看0 / 25 / 50 / 75 / 100%五个画面，暂不接管页面。

渲染器添加独立的演出状态（scale、整体位移、亮灯强度）。镜头与演出分离，人物原动画先求值，再应用整组变换。以球心C0与顶部锚点A0计算：C(p)=A(p)−s(p)(A0−C0)，P(p)=C(p)+s(p)(P0−C0)。灯光、阴影坐标、火光距离衰减必须在同一空间；优先在原场景坐标采样静态阴影，再将整组变换用于投影，避免缩放后火光突然变强。

当前顶部切平面倒影不能直接覆盖完整球体。缩小时淡出局部倒影，先使用已有环境贴图呈现整球；如需保留人物倒影，再评估球面探针，不把新重型反射系统作为首版前置条件。检查完整球下半部、背面与近远裁切面，不能只缩Canvas。

点亮只驱动球的环境反射、填缝自发光及克制光晕，不改变人物皮肤、火焰亮度或主题。吊线使用球挂点的真实屏幕投影，DOM/SVG位于场景后方，不能穿过人物。

验收：五帧中无穿插/裁切/比例滑移，暗亮两端均可辨认网格，原色和1-bit都可用。

### 2. 首页接管一次下滑

用useGSAP管理唯一Observer与时间线，限定Hero区域，不给全站注册永久preventDefault。状态为近景→演出中→悬挂→普通正文；只有处于Hero且资源ready、无reduced-motion时才能接管。

- 从近景下滑播放；演出中同向滚轮不重复触发，反向手势平滑反转当前时间线。
- 停在悬挂态后，下一次明确下滑释放滚动；过滤同一触控板手势尾部惯性，避免刚停稳就飞走。
- 从正文上滑返回Hero顶部可反向收回，完成后恢复触发前镜头与控制面板。
- 滑块、按钮、链接、键盘焦点不被Observer吞掉；支持键盘PageDown/Space与PageUp在Hero内的同等进入/返回，Esc直接释放接管。
- 路由切换、加载失败、WebGL上下文丢失及组件卸载一律解锁；不得覆盖用户既有body样式而无法恢复。
- reduced-motion不接管，显示静态近景并正常滚动；不自动播放缩放/升降/亮灯。

终态之后先接现有内容/页脚，不在这项任务新增正文内容。当前首页没有ScrollSmoother，由这一个编排模块负责；不与归档页Observer同时挂载。

### 3. 完整走查后上线

桌面和390/360px手机检查：首次下滑、半程反向、连续快滑、触控板惯性、终态离开与返回、滑块拖动、键盘、刷新恢复位置、窗口变化、切后台、页面卸载、资源失败及减少动态效果。先保证无锁滚和场景漂移，再打磨节奏。

通过lint/build；在运行的开发页面实际验证WebGL和输入，保存近景/缩小中段/亮灯/悬挂截图。页面目测不可用时保留待验，不以HTTP成功替代视觉验收。

## 本轮与后续边界

本轮落地默认镜头和暗镜面材质，保留其他材质方案；本文件是后续路线。实施顺序为Lab进度试作→确认完整球与亮灯→首页手势接管→多设备回归。暂不恢复旧旋转/卷纸动画，也不增加灯球点击坠落。
