### 哈利篝火 Lab（2026-10-07）

- 2026-10-15 网页同步允许性能优先近似源场景精修：静态单段倒角、顶点粗糙度预计算，暗缝弱受光；原色512px倒影且按源动画帧更新，镜头变化立即更新；双色保留原风格并跳过局部倒影通道。

- 2026-10-15 灯球源场景精修覆盖此前粗糙度完全不变的限制：允许克制的粗糙度变化、薄镜片厚度及细小倒角，暗缝不发光，不改变分片布局和人物构图；网页双色现有风格保留。

- 2026-10-14 细节精修：面部和手部使用独立的柔和亮度压缩，保留源贴图明暗；亮部不一刀切成白块。手指仅旋转关节，避免移动指根拉裂蒙皮；左掌顺腿面、右指与拇指包住杆。Blender 整理旧灯并加入可编辑低强度辉光和调色，网页空气透视在双色量化之前处理；不对整张双色画面模糊，不改变灯球的既有双色风格。

- 2026-10-14 修复：双色火光主导明暗，朝火受光面更亮，环境补光不能颠倒光源方向；两手使用源骨骼自然握持/搭腿。火星沿世界向上升起、轻微横向漂移、淡出重生，两种材质共用轨迹；暂停与 reduced-motion 停止。

- 2026-10-11 双色人物重做：人物、石圈与木柴采用独立的法线受光/火光遮挡、明暗分区和轮廓线，低亮材质不直接决定暗部，颗粒只用于窄过渡区；火焰以清晰亮形和不透明核心为主，烟雾低密度处理，避免层层半透明量化导致的碎点。此要求替代上一版人物直接 Standard + 蓝噪声全范围量化；灯球保持此前首页资产风格。

- 2026-10-11 双色调整：双色灯球沿用当前首页灯球的源镜片/环境、白色填缝、Standard 亮度与 2px 蓝噪声量化（共用 blue-noise-128.png）；此要求覆盖此前「双色也关闭填缝」规则。人物和火堆双色光照单独提亮，保留阴影轮廓。两种模式均模糊局部倒影，镜片边缘保持清楚。双色背景增加轻微静态颗粒和稀疏缓慢飘动粒子，暂停/reduced-motion 时静止。

- 2026-10-11 暗场修正：扩大球面半径至约 14，保持源镜片倾角及材质参数；首屏以火光为主，环境仅弱补光，镜片反射有方向与明暗层次，填缝不发白光。线性空间照明、金属微表面反射、火光衰减及阴影使人物落在球面上。原资产完整亮灯风格保留供未来转场，当前只展示暗场。

- 2026-10-11 巨大灯球：地面换为 orb-master 的真实镜片和填缝球体，移除泥地/草/散石；哈利稍靠近并放大，人物、脚和石圈贴合顶部弧面。默认球径超出画幅，保持主体与火焰可读，原色使用资产镜面环境、双色沿用 token。Hero 整体缩小和吊起的方案先写计划，不在本轮接管首页。

- 2026-10-11 可旋转版本例外：将固定镜头序列替换为原生 WebGL 三维视图，使用指定 Animated 篝火的网格与动画。哈利坐在地面，镜头拉近；拖动环绕、滚轮缩放、方向键转动及按钮复位。原色默认、双色 token 保持；GSAP 驱动播放，reduced-motion 静止动画但允许用户主动转动视角。

- 2026-10-09 风格改为早期 Source / Half-Life / Garry’s Mod 视觉习作：低面数但边界清晰，低分辨率灰暗噪点贴图及硬阴影，不模糊画面。默认展示材质原色，双色作为可选对照；保留既有姿态、镜头和单人构图。
