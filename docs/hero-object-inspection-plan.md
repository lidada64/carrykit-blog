## 体验顺序

1. 悬停或键盘聚焦：沿用细轮廓与入口名称，物件不持续漂浮。
2. 点击：选中的物件从原位置抬起，移到画面中央并转向展示面；其他场景轻微压暗，保持原构图，不加模糊。
3. 停稳：允许拖动旋转查看，上方出现名称，下方出现简短描述和“进入”按钮。鼠标拖动与触摸滑动只操作物件，不触发灯球吊起。
4. 关闭或 Esc：沿原路径归位，恢复原朝向、镜头及键盘焦点。点击进入按钮才导航。

账簿重点展示纸页和封皮；笔记本展示封面与侧边，不虚构现有静态模型没有的翻页结构；收发器转到面板与旋钮可见的角度。三者共用一次短促抬起与缓停节奏，不做无限旋转。

## 实现边界

- 给现有三个网格增加独立模型变换，复用几何、材质与加载结果；检视期间只绘制一份物件，原位置不留复制体。
- 状态为 idle / opening / inspecting / closing；只允许一个物件检视。开合期间关闭另两个热区，快速重复点击不积累时间线。
- GSAP 经 useGSAP 管理，时长及缓动集中 motion tokens。归位完成前暂停 Hero 滚动转场，卸载时释放事件和动画。
- 可访问对话框承载名称、进入和关闭按钮；限制焦点范围并恢复触发元素。保留语义链接支持打开新标签页。
- reduced-motion 直接切换展示状态，停用飞行、旋转和回弹；键盘使用方向键旋转并提供复位按钮。
- 手机使用画面上部展示模型、下部介绍和按钮，保留安全区，不要求精细拖动才能进入页面。中英文文案同步。

## 验收

- 三物件分别进入/归位，途中关闭、连点、切换尺寸及路由卸载无残影或重复模型。
- 拖动不会触发滚动吊球；关闭后原有滚动与场景控件恢复。
- 桌面、390px、键盘、减少动态均可完成检视和导航；原色与双色下展示面可辨。
- lint/build 通过，本地页面视觉及交互验证后再标为完成。
