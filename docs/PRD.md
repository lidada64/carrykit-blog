# PRD — 个人博客/作品集网站 需求文档

> 版本:v2.0 | 日期:2026-07-07 | 来源:[Target.md](../Target.md)
> 状态:已确认(v2:动效/布局按参考站深度调研修订;新增扩展性接口与 UI 语言切换)

## 1. 项目背景与目标

制作一个用于展示个人作品与想法的前端博客网站,包含前后端与数据库,最终部署到自有 VPS。

**核心目标(按优先级)**:

1. **可扩展性** — 数据模型、路由、组件均为后续功能(标签、评论、i18n)预留扩展点
2. **可运行** — 每个里程碑结束时项目都处于可构建、可部署的状态
3. **美观** — 参考 [lokasasmita.com](https://www.lokasasmita.com/) 的页面布局与动画效果,极简、大留白、细腻动效

**设计参考**(第一优先级):

- https://www.lokasasmita.com/ — 首页布局、hero 标语、导航
- https://www.lokasasmita.com/blog — 博客列表样式
- https://www.lokasasmita.com/blog/the-creative-website-guide — 文章详情页排版

## 2. 用户角色

| 角色 | 描述 | 入口 |
|------|------|------|
| 访客 | 浏览作品、阅读博客、获取联系方式 | 公开页面 |
| 站主(Admin) | 撰写/管理博客与作品,单用户 | `/admin`(需登录) |

## 3. 功能需求

### 3.1 Home 页(默认路由 `/`)

> Target 原文:"当用户没有选中任何页面时,展示 home 页"

- **US-H1**:访客打开根路径时看到 hero 区:大字标语(个人 slogan)+ 入场动效
  - 验收:首屏渲染标语,文字带 fade + up 入场动画;移动端不溢出
- **US-H2**:hero 下方展示精选作品(最多 3 个)与最新博客(最多 3 篇)入口
  - 验收:点击可跳转到对应详情页;无内容时该区块优雅隐藏
- **US-H3**:全站统一导航:logo + work / blog / about / contact(contact 为 mailto 链接)+ 语言切换按钮
  - 验收:所有公开页面共享同一导航;当前页高亮
- **US-H4**:首次访问时播放 preloader:数字 counter 计数 + 遮罩揭示进入 hero(对齐参考站)
  - 验收:同一会话内(sessionStorage)不重复播放;`prefers-reduced-motion` 时跳过

### 3.2 About 页(`/about`)

> Target 原文:"展示个人信息与联系方式"

- **US-A1**:展示个人介绍(头像可选、姓名、简介段落)
- **US-A2**:展示技能/关注领域列表
- **US-A3**:展示联系方式:email + 社交链接(GitHub 等)
  - 验收:email 为 `mailto:` 链接;社交链接新标签页打开

### 3.3 Blog 页(`/blog`、`/blog/[slug]`)

> Target 原文:"展示想法"

- **US-B1**:列表页为**双栏布局**(对齐参考站):左侧 sticky 侧栏(`Blog(N)` 标题、栏目描述、缩略图),右侧文章列表(`DATE / NAME` 表头 + 行:日期 `YYYY.MM.DD` + 标题),按发布时间倒序
  - 验收:仅显示 `PUBLISHED` 状态文章;整行可点击;hover 时日期与标题有文字滚动动效(DESIGN_SPEC A3);移动端降级单栏
- **US-B2**:列表页侧栏含栏目简介与文章计数(如 `Blog(3)`)
- **US-B3**:详情页渲染 Markdown 正文:标题层级、图片、代码块(语法高亮)、列表、引用
  - 验收:正文排版遵循 [DESIGN_SPEC.md](DESIGN_SPEC.md) 的字号阶梯;移动端可读
- **US-B4**:详情页结构对齐参考站:顶部大缩略图 + 标题 → 左侧 metadata 侧栏(描述、日期、标签)+ 右侧正文
  - 验收:与 DESIGN_SPEC §6 线框一致;无缩略图时头图区优雅隐藏
- **US-B5**:详情页底部展示 Related Articles 卡片网格(≤3 篇其他文章),并有阅读进度条
  - 验收:进度条随滚动增长;不足 2 篇相关文章时该区块隐藏

### 3.4 Work 页(`/work`、`/work/[slug]`)

> Target 原文:"展示个人作品"

- **US-W1**:列表页为**滚动驱动画廊**(完整复刻参考站,DESIGN_SPEC A5):滚动时作品大图依次切换、序号数字翻转、右侧作品名列表 indicator 随滚动高亮、底部进度条;按自定义 `order` 排序
  - 验收:桌面端滚动可遍历全部作品并点击进入详情;**移动端(< md)降级为纵向作品卡片列表**;`prefers-reduced-motion` 降级为静态列表
- **US-W2**:详情页展示作品完整信息:封面图、描述正文(Markdown)、技术标签、外部链接(演示/仓库)
  - 验收:外链新标签页打开;无外链时按钮不显示

### 3.5 Admin 管理后台(`/admin/**`)

- **US-M1**:登录页,单用户凭据(环境变量或数据库存储的哈希密码),session 鉴权
  - 验收:未登录访问 `/admin/**` 重定向到登录页;密码不以明文存储
- **US-M2**:博客管理:列表、新建、编辑、删除;字段:标题、slug、摘要、正文(Markdown)、封面图(支持上传或外链 URL)、标签(逗号分隔)、状态(草稿/发布)、发布时间
  - 验收:草稿不出现在公开页;slug 唯一,冲突时提示;封面图上传后自动转 WebP 并压缩
- **US-M3**:作品管理:列表、新建、编辑、删除;字段:标题、slug、一句话描述、正文、封面图(支持上传或外链 URL)、技术标签、外链、排序值
  - 验收:同 US-M2 封面图上传验收
- **US-M4**:Markdown 编辑器带预览(编辑/预览切换即可,不要求实时双栏);支持插入上传图片(上传后自动在光标位置插入 `![](url)`)
  - 验收:插入的图片在预览模式与前台详情页均正常渲染

### 3.6 全局体验

- **US-N1**:路由切换时播放 revealer 页面过渡:遮罩滑入覆盖 → 新页就绪 → 遮罩滑出(DESIGN_SPEC A1)
  - 验收:全部公开页面路由切换生效;`prefers-reduced-motion` 降级为 fade;admin 不启用
- **US-I1**:UI 语言切换:导航提供 `EN/中` 切换,界面文案(导航、标签、栏目简介、表头等)在英文/中文间切换;**默认英文**
  - 验收:切换即时生效并以 localStorage 持久化;博客/作品正文内容不参与切换(单语);所有 UI 文案来自 `src/i18n/` 字典,无组件内硬编码

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| SEO | 公开页 SSG/ISR 渲染;每页独立 `<title>`/`<meta description>`;`sitemap.xml`、`robots.txt`;文章页 OG 标签 |
| 性能 | 公开页 LCP < 2.5s(VPS 环境);图片使用 `next/image` 优化 |
| 响应式 | 移动端(≥360px)、平板、桌面三档断点均正常显示 |
| 动效 | 遵循 DESIGN_SPEC §5 动效清单(GSAP),以参考站为复刻准绳;支持 `prefers-reduced-motion` 降级 |
| 可扩展性 | **三个单点修改接口**(见 [ARCHITECTURE.md](ARCHITECTURE.md) §7):① 字体只改 `src/config/fonts.ts` ② 主题色只改 globals.css token 块 ③ UI 文案只改 `src/i18n/` 字典;另:数据模型预留 tag 字段、暗色模式预留 `[data-theme]` 结构 |
| 安全 | admin 密码哈希存储;API 写操作全部要求鉴权;无密钥硬编码 |

## 5. 不做清单(V1 明确排除)

- ❌ 评论系统
- ❌ 全文搜索
- ❌ 多用户 / 权限体系
- ❌ **内容双语**(博客/作品正文的中英双份维护;UI 文案切换 V1 已含,见 US-I1)
- ❌ 文章目录 TOC(参考站无此设计,进 V2 候选)
- ~~图片上传服务~~ — 已实现,见 US-M2/M3/M4 及 [ARCHITECTURE.md](ARCHITECTURE.md) §5.1
- ❌ RSS(V2 候选,成本低可提前)
